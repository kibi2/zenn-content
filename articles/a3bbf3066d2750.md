皆さんは Chromium 用拡張機能 **Vimium** をご存じでしょうか。

Vimium を使うと、ブラウザを Vim ライクにキーボードだけで快適に操作できます。

この記事では Vimium の基本的な使い方は扱いません。基本操作については他の記事に譲り、本記事では **リンクを選択する Hint 機能** とカスタマイズ方法をご紹介します。

## この記事を読むとできること

* マウスを使わず、キーボードだけで素早くリンクを開けるようになります。
* リンクの Hint を読む代わりに、リンクの文字列を入力して目的のリンクを絞り込めるようになります。
* Hint を数字ではなくホームポジションで入力しやすい英大文字に変更できます。
* 数字を含むリンク（Wiki のカレンダーや日付など）を数字で絞り込めるようになります。

## リンクを選択する Hint 機能

`f` キーを押すと、ページ内のリンクの横に Hint が表示されます。

表示された Hint を入力するだけで、目的のリンクを開くことができます。

マウスに手を伸ばす必要がないため、Vimium を代表する便利な機能の一つです。

## リンクの文字列でリンクを開く

さらに便利なのが、Options にある次の設定です。

> **Use the link's name and characters for link-hint filtering**

この設定を有効にすると、Hint を入力する代わりに **リンクの文字列** を入力してリンクを絞り込めるようになります。

例えば **Cancel** ボタンがある場合、

```
f
ca
Enter
```

と入力するだけで Cancel ボタンを押すことができます。

毎回 Hint を読む必要がなくなるため、非常に快適です。

## この機能の難点と解決策

この機能は非常に便利ですが、Hint が数字になるという難点があります。

* 数字キーはホームポジションから遠く、入力しづらい。
* 日付一覧で`28` のようなリンクを開きたくて `28` と入力しても、Hint の `28` と解釈されてしまう。

これを解決するため、Options の **Numbers used for link hints** を次のように変更します。

```
SDFGHJKLYUIONMERTVBC
```

ポイントは **大文字** を使うことです。押しやすいキーを選び、好みに応じて追加・削除してください。

Vimium は、Hint に使用する文字を text filtering の入力としては扱いません。

そのため、Hint に英大文字を割り当てると、英大文字は Hint の入力に、小文字と数字は text filtering の入力に利用できます。

また、text filtering は英字の大文字・小文字を区別しないため、リンクの文字列はこれまでどおり小文字で入力できます。

この設定にすると、

* Hint はホームポジションで入力しやすい英大文字になります。
* 数字は text filtering に使われるため、カレンダーの日付や数値を含むリンクも数字を入力して絞り込めます。

## おまけ

Vimium には **Custom key mappings** という機能もあります。

ここをカスタマイズすると、Vimium をさらに快適に使えるようになります。

参考までに、私が使っている設定を紹介します。

```vim
# Navigating the page
unmap d
unmap u
map <c-f> scrollFullPageDown
map <c-b> scrollFullPageUp
map <c-d> scrollPageDown
map <c-u> scrollPageUp
map M Marks.activateCreateMode swap
map m Marks.activateGotoMode swap

# Manipulating tabs
map do closeOtherTabs
map dh closeTabsOnLeft
map dl closeTabsOnRight
map dd removeTab
```

標準では`u`と`d`がスクロール操作に割り当てられています。しかし、この操作に慣れてしまうとVimでも誤って`u`や`d`を押してしまうことがあったため、私は`Ctrl+U`、`Ctrl+D`に変更しています。

また、`M`と`m`の割り当ても、操作しやすさを優先して変更しています。
