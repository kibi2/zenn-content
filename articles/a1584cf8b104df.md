### デモ

![](https://storage.googleapis.com/zenn-user-upload/287d22a14589-20260317.gif)

CSVファイル開いて、dd, p, a, undo/redo, motion, :Tir toggle など

### インストール

#### lazy.nvim

```lua
{
  "kibi2/tirenvi.nvim",
  config = function()
    require("tirenvi").setup()
  end,
}
```

#### CSV パーサーをインストール

```bash
pip install tir-csv
```

### 使い方

以下の拡張子のファイルを開くと自動的に有効になります。

* `.csv`
* `.tsv`

### コマンド

| コマンド          | 説明                          |
| ------------- | --------------------------- |
| `:Tir redraw` | 列幅を再計算する                    |
| `:Tir toggle` | 生のテキスト表示 ↔ 構造化テーブル表示 を切り替える |

すべての通常の Vim 編集操作がそのまま使えます。
特別な編集モードはありません。

### 列編集

列は構造的な単位として扱われます。

列を編集するには：

1. Visual Block モード (`<C-v>`) に入る
2. 縦方向に選択する
3. 通常の演算子 (`d`, `p` など) を適用する

テーブル構造を壊す操作は自動的に補正されます。

### Pipe モーション

セル間を高速に横移動するためのモーションです。

```lua
vim.keymap.set({ 'n', 'o', 'x' }, '<leader>tf', require('tirenvi').motion.f, { expr = true })
vim.keymap.set({ 'n', 'o', 'x' }, '<leader>tF', require('tirenvi').motion.F, { expr = true })
vim.keymap.set({ 'n', 'o', 'x' }, '<leader>tt', require('tirenvi').motion.t, { expr = true })
vim.keymap.set({ 'n', 'o', 'x' }, '<leader>tT', require('tirenvi').motion.T, { expr = true })
```

これは Vim の `f / F / t / T` と同じように動作しますが、
**テーブルの区切り文字（列境界）を対象に移動します。**

`;` と `,` による繰り返しも通常通り使用できます。
