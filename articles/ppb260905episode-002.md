前回は、okozeを始めた理由と、このプロジェクトを通して考えてみたいことを書きました。

今回は、実際にokozeを作るための開発環境を決めます。

## Webアプリケーションか、スタンドアロンアプリケーションか

大きく分けると、次の2つの方法があります。

* Webアプリケーション
* スタンドアロンアプリケーション

スタンドアロンアプリケーションなら、OSに直接アクセスできますし、Webプラットフォームによる制約も避けることができます。

一方、今回のokozeにはWebアプリケーションにも魅力があります。

複数のOS向けに別々のバージョンを用意しなくても、多くの環境で動かせる可能性があります。

そして、Webアプリケーションなら、**GitHub Pagesでそのまま公開できます。**

読者はソフトウェアをインストールしなくても、その時点のokozeを実際に動かしてみることができます。

**okozeはWebアプリケーションとして開発することにします。**

## 開発マシン

開発には、今持っているマシン(**Mac mini M4**)を使います。

okozeそのものは、このハードウェアに依存しないようにします。

## プログラミング言語

最初は**JavaScript**を使います。

小さなWebアプリケーションのプロトタイプを作るには、JavaScriptが一番素直な選択だと思います。

ただし、プログラムが大きくなれば、いずれTypeScriptが役に立つだろうとも考えています。

## IDE

IDEには**Visual Studio Code**を使います。

Web開発で広く使われていますし、JavaScript、TypeScriptのサポートも充実しています。

Visual Studio Codeそのものの使い方については、ここではあまり詳しく説明しません。

## ブラウザ

開発とテストには、**Chromium系のブラウザ**を使います。

ChromiumにはDeveloper Toolsがあり、アプリケーションの調査、ログやエラーの確認、プログラムの動作確認などに便利です。

## グラフィックス

okozeの主要なグラフィックス部分は、最初はブラウザの**Canvas API**を使います。

最初のプロトタイプでは、グラフィックスライブラリを導入せず、Canvasを直接使ってみます。

okozeをある程度実装して必要な機能が分かってきたところで、利用できるグラフィックスライブラリを調べ、比較してみたいと思います。

## バージョン管理

ソースコードは**Git**で管理し、**GitHub**に置きます。

GitHubのリポジトリを、単に最新のソースコードを置く場所として使うだけではなく、開発過程の記録としても使いたいと思っています。

okozeの開発で一つの段階が完成したら、Gitのtagを付けて、Live Demoとして公開します。

* その時点のokozeがどんなものだったか
* そのバージョンを作ったソースコードは何だったか

の両方を確認できます。

## AIを使ってプログラミングする

コードを書くときには、**AIを積極的に使います。**

これは前回書いた、この連載の実験の重要な部分でもあります。

このプロジェクトでは、AIを**プログラミングのパートナー**として使います。

実装についてAIに相談し、生成されたコードを調べ、実際に動かし、テストし、次に何をするかを決めます。

## 私のWeb開発経験について

私の主な専門分野は、**CADと幾何処理**です。

長い間ソフトウェア開発をしてきましたが、Webアプリケーションの開発経験はほぼありません。

つまり、プログラミングやグラフィックスについてはそれなりに経験がありますが、Webプラットフォームについては、知らないことばかりです。

そのため、この連載で書くWeb開発についての説明には、驚くほど基本的なものや、少し素朴なものが出てくるかもしれません。

## 開発環境

最初の開発環境をまとめると、次のようになります。

| 目的               | 使用するもの            |
| ------------------ | ----------------------- |
| 開発マシン         | Mac mini M4             |
| IDE                | Visual Studio Code      |
| ブラウザ           | Chromium系ブラウザ      |
| 開発サーバー       | Live Server             |
| プログラミング言語 | JavaScript → TypeScript |
| グラフィックス     | Canvas API              |
| バージョン管理     | Git / GitHub            |
| Live Demo          | GitHub Pages            |
| コーディング支援   | AI                      |

まずはこの環境を作って、実際にコードを書いてみます。

そして、実際に開発してみることで、今決めたことがうまくいくのかどうかを確かめていきます。

次回は、この開発環境を実際に構築します。
