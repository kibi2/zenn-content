皆さんは、ブラウザのテキスト編集エリアで vi のコマンドを使いたいと思ったことはありませんか？

コピー＆ペーストを使えば一応できますが、正直かなり面倒です。

Wenvi は、このコピー＆ペースト作業を完全に肩代わりするために作りました。

ブラウザ上の入力欄を一時的に Neovim に持ち出して編集し、結果を自動で書き戻すツールです。

Chrome拡張のvimiumと組み合わせればマウスに持ち変えることなく快適にブラウザの操作ができます。

またChatGPTのブラウザ版などで日本語変換のつもりでEnterキーを押して誤送信したことはありませんか？私はしょっちゅうです。Wenviではneovimで編集するので誤送信することはありません。

同じようなことができる製品は他にもあります。

Wasavi：これは私のお気に入りで長い間使っていました。ですがいつの間にか使えなくなりました。 今回wenviを開発したのもこれがきっかけです。

Firenvim：私の環境では日本語入力と相性が悪く使えませんでした。

GhostText：双方向にリアルタイム同期する、非常にクールな製品です。
ただ、エディタとブラウザの切り替えにマウス操作が必要になる点が、 キーボードだけで作業を完結させたい私には不満でした。 また、ChatGPT などの contenteditable な編集エリアでは使えない点も難点でした。

Wenvi：もう１ヶ月以上毎日のように使って、使いにくいところは改善しました。今ではとても快適に使えています。

興味のある方は一度覗いてみてください。

# wenvi

ブラウザで編集可能なコンテンツをNeovim を使って編集します。
コピー＆ペーストは完全に自動化されています。

**wenvi** は、編集可能な要素 (textarea、input、またはcontenteditable) のコンテンツを一時的に抽出し、Neovim で開き、編集完了時に結果を書き戻します。

ブラウザ拡張機能は不要です。
手動でのコピー＆ペーストは不要です。
ブラウザ外で Neovim のみを使用します。

## 機能

* ブラウザで編集可能な要素 (textarea、input、またはcontenteditable)を Neovim で編集します。
* 終了時に編集内容を自動的にブラウザに同期します。
* 編集バッファを `dataHome` (デフォルト: `~/.cache/wenvi`) に保存し、grep, diffなどが使用できます。
* ファイルをドメイン別に整理し、ファイル名にページタイトルを含めます。

## 要件

* macOS、Neovim、Hammerspoon、Chromiumベースのブラウザ、Python（tomlモジュール）

## インストール

```bash
git clone https://github.com/kibi2/wenvi.git ~/wenvi
cd ~/wenvi
cp examples/hammerspoon/wenvi_config.lua.example ~/.hammerspoon/wenvi_config.lua
mkdir -p ~/.config/wenvi/
cp examples/config.toml.example ~/.config/wenvi/config.toml
```

> `wenvi_config.lua` 内のパスを環境に合わせて編集してください。
> また、必要に応じて `config.toml` の内容を調整してください。

Neovim の init の例:

```lua
vim.opt.runtimepath:append('/path/to/wenvi_home/editor/nvim')
require 'wenvi'
````

> `/path/to/wenvi_home/` を環境に合わせて編集してください。

## 使用方法

* ブラウザページを開き、&#8984;E を押します (ショートカットは変更可能です)。
  * ~/wenvi/platforms/macos/hammerspoon/wenvi/init.lua
* Neovimが起動しテキストを自動で読み込みます。
* Neovim でテキストを編集します。バッファを閉じると、変更内容が自動的に書き込まれます。
