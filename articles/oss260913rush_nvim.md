# rush.nvim — Vimのカーソル移動をもう少し楽にする

Vim / Neovimを使っていると、カーソル移動について「もう少し何とかならないかな」と思うことがあります。

特に日本語の長い文章を書いているときです。

## なぜ作ったのか

Vimには、カーソルを移動するためのコマンドがたくさんあります。

`h` `j` `k` `l` で少しずつ移動できます。

`w` や `b` なら単語単位で移動できますし、`0` や `$` を使えば行の端にも移動できます。

さらに、カウントを付ければ、

```text
10j
```

のように一気に10行移動することもできます。

つまり、

**小さく移動する方法と、大きく移動する方法はかなり充実しています。**

ところが、その中間がちょっと困ります。

例えば「5〜6行くらい下に行きたい」というとき。

```text
jjjjjj
```

と入力するのも面倒です。

かといって、

```text
6j
```

と入力するのも、文章を書いている途中では少し大げさです。

日本語の文章を書いていると、こういう「ちょっと先」「ちょっと戻る」という移動が意外と頻繁にあります。

そして私は、結局マウスを手に取って、目的の場所をクリックしてしまいます。

キーボードだけで操作したいのに、ここでマウスに手が行ってしまう。

これが気になっていました。

そこで、

> **同じ移動キーを連続して押したら、だんだん移動量を大きくしたらいいのでは？**

と思いました。

それを試すために作ったのが `rush.nvim` です。

## rush.nvimでできること

基本的な考え方は単純です。

同じキーを連続して押すと、移動量が大きくなります。

例えば `j` を使った場合、

```text
j
jj
jjj
jjjj...
```

と続けて入力するにつれて、カーソルが進む距離が大きくなっていきます。

最初は普通の `j` と同じように少しだけ移動し、連続入力すると一気に先へ進めます。

`j` だけでなく、`k`、`h`、`l` にも使えます。

つまり、

```text
小さく移動
    ↓
同じキーを続けて押す
    ↓
だんだん速く移動
```

という感じです。

普段のVimの操作を大きく変えるのではなく、**よく使うカーソル移動を少しだけ速くする**ことを狙っています。

## インストール

lazy.nvimなら、例えば次のようにインストールできます。

```lua
{
  "kibi2/rush.nvim",
  opts = {},
}
```

インストールしたら、あとは普段どおり `h` `j` `k` `l` を使うだけです。

設定によって移動量を変更することもできます。

## おわりに

rush.nvimは、ものすごく高度なことをするプラグインではありません。

「カーソルをもう少し楽に動かしたい」という小さな不満から作ってみたプラグインです。

実際に使ってみると、文章を書くときのカーソル移動で意外と便利でした。

同じように、

> 「ここでマウスに手を伸ばしてしまう」

ということがある方は、よかったら試してみてください。
